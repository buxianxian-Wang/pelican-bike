# 鹈鹕骑单车 · Pelican on a Bike 🚴🦩

> 一只戴着头盔和围巾的白鹈鹕,骑着复古自行车沿海岸线追鱼。
> **实时 3D**:程序化建模、IK 骨骼踩踏、Verlet 布料围巾、Gerstner 海浪、
> 昼夜循环、多机位电影运镜与实时合成音乐——全部零依赖,一个 Canvas 跑起来。

---

## 🎮 操控

| 按键 | 动作 |
| --- | --- |
| `W` / `S`(或 ↑↓) | 加速 / 减速 |
| `A` / `D`(或 ←→) | 三车道变道追鱼 |
| `空格` | 跳跃 |
| `Q` / `E` | 换档(1-5 档,影响最高速度与踏频) |
| `T` | 撒把特技 |
| `B` | 车铃 · `H` 鹈鹕嘎叫 |
| `C` | 切换镜头:自由环绕 / 追随 / 侧面跟拍 / 电影运镜 / 鹈鹕视角 |
| `N` | 时间快进 3 小时(昼夜循环) |
| `M` 音乐 · `K` 拍照 · `P` 暂停 · `U` 隐藏界面 · `F` 全屏 |

**鼠标:** 拖拽旋转视角(自动切到自由环绕)· 滚轮缩放 ·
点鹈鹕它会嘎 · 点车铃会响 · 点海面会有鱼跃出。
**闲置 6 秒**,鹈鹕会自己变道追鱼巡航。

**玩法进阶:** 普通鱼 +1、金鱼 +5;2.2 秒内连续吃鱼累积**连击**,
连击 ×5 奖励 +2;每收满 10 条触发**鱼群来袭**(多车道撒鱼)。
收获的鱼会真实地堆进车筐,喉囊也会满足地鼓一下。
高速骑行(>5.2m/s)出现速度线,HUD 速度数字变金变橙。

## 🚀 运行方式

**双击 `index.html`** 即可(Chrome / Edge),或:

```bash
cd 鹈鹕骑自行车
python -m http.server 8420   # 打开 http://localhost:8420
```

零依赖、零构建、零外部资源——3D 引擎与全部内容均为手写,不需要 WebGL/Three.js/CDN。

## 🧱 技术架构

```
js/
├── engine3d.js   3D 引擎:向量/椭球/圆管/圆环/圆盘网格、lookAt 相机、
│                 透视投影、近平面多边形裁剪、双面光照、画家算法、距离雾
├── world3d.js    海岸世界:滚动公路、Gerstner 海浪 + 岸边泡沫浪线、
│                 地平线岛屿剪影、棕榈/路灯/长椅/遮阳伞/礁石(带投影)、
│                 海鸥、昼夜天空/日月星辰、夜景路灯光晕 + 车灯光锥
├── pelican3d.js  程序化鹈鹕+自行车:IK 踩踏、扶把/展翅、Verlet 围巾、
│                 接地阴影、车筐堆鱼、喉囊鼓动
├── fish3d.js     车道巡游鱼群(普通/金鱼/鱼影)、抓取判定、
│                 点击海面跃鱼、鱼群来袭
├── audio3.js     WebAudio 全合成:五声音阶生成式音乐(随踏频)、
│                 海浪、车铃/嘎叫/吃鱼/水花/海鸥叫
└── game.js       主控制器:五档骑行物理、五机位相机、昼夜(8 分钟一天)、
                  连击/鱼群系统、成就、点击互动、闲置自动驾驶、速度线、HUD
```

- **渲染**:Canvas 2D 多边形光栅化,每帧 ~7000 面,画家算法 + 平面着色。
- **鲁棒性**:后台标签自动暂停 + 定时器降级;隐藏画布尺寸兜底;
  `localStorage` try/catch;渲染循环单帧异常不中断。
- **测试钩子**:`PT.main3d.testStep(dt)` / `PT.main3d.snapshot(w)`。
